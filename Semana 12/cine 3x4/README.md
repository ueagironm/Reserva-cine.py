Asignatura: Fundamentos de Programación

## Objetivo del programa

Crear un sistema de reserva de asientos para una sala de reuniones de 3 filas por 4 columnas, utilizando una matriz bidimensional y bucles anidados. El programa permite reservar un asiento ingresando su fila y columna, y muestra el estado completo de la sala:

- 0 = Asiento libre
- 1 = Asiento reservado

## Cómo ejecutarlo

1. Abrir el archivo Reserva cine.py en Visual Studio Code
2. Ejecutar el programa con Python
3. Ingresar el número de fila (del 1 al 3)
4. Ingresar el número de columna (del 1 al 4)
5. El sistema registra la reserva y muestra la sala actualizada

## Estructura

- Matriz de 3 filas y 4 columnas, inicializada en ceros
- Validación de que fila y columna estén dentro del rango permitido
- Visualización de la sala en formato de tabla
